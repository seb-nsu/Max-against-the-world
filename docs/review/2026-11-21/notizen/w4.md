                       ├─ R4a–d vier Alibis ─ R4 Hyäne ─ Rückspulen ┼─ R9 Bonusrunde ─ Adapter ─┐

                       └─ Banane nehmen (Grusel, Comic)
R6 ─ R7 Lichterkette ─ R8 Agent (oder Sonnenbrille) ─ Untertitel
R10 + Stumm + Stinkbombe ─ R11b–d ─ Sendersuchlauf ─ R12a Empfang ─ (R7, Archivband, Untertitel, Pause) R12b ─ R13 Zappmann

Vor R4 kann der Spieler nur R3, R5a, R10a, R10b, R11a und die Banane erledigen.
